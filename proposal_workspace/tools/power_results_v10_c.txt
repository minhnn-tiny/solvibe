Part C, seeded validation: 95% half-width of the paired recall difference = 1.96 * sqrt(deff * (delta - d^2) / n)
  n matched pairs (one seed in the human implementation, the same seed in an agent implementation of the same function)
  delta = probability that exactly one of the pair is detected; d = true recall difference (0.1); deff = 1.5 for clustering
  delta 0.2: n=60: 0.135, n=120: 0.096, n=240: 0.068, n=480: 0.048
  delta 0.3: n=60: 0.167, n=120: 0.118, n=240: 0.083, n=480: 0.059
  delta 0.4: n=60: 0.194, n=120: 0.137, n=240: 0.097, n=480: 0.068
