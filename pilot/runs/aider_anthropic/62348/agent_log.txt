The implementation:                                                             

 1 Reads the current state using self.fungibleStates[fungible] and extracts the 
   index and balance                                                            
 2 Returns false if not held (index == 0)                                       
 3 Reverts if insufficient balance using a require statement                    
 4 Updates balance if still positive by creating a new state with the same index
   and new balance                                                              
 5 Removes completely if balance becomes zero by:                               
    • Clearing the fungible state mapping entry                                 
    • Removing from the array using swap-and-pop (like removeNonFungible)       
    • Updating the moved fungible's state with its new index (the critical      
      difference from non-fungibles)                                            
 6 Returns true when removal was applied                                        

The key insight is that when we swap the last element into the removed position,
we must update that moved fungible's state to reflect its new index in the      
array, maintaining the invariant that fungibleStates[f].index() always equals   
the 1-based position of f in the fungibles array.
